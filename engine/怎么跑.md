# 引擎怎么跑

## 三种运行模式

| 命令 | 干什么 | 要不要 key | 要不要邮箱 |
|---|---|---|---|
| `python triage.py --demo --open` | 看成品长什么样（内置假数据） | 不要 | 不要 |
| `python triage.py --testai --open` | **真 AI 跑 3 封样本，验证 key 和输出质量** | 要 | 不要 |
| `python triage.py --open` | 真跑，连真实 Gmail | 要 | 要 |

## 双引擎，随时切换

`config.json` 里 `provider` 一个字段决定用哪个：

| provider | 成本 | 拿 key 的地方 | 适合 |
|---|---|---|---|
| `deepseek` | 约 **¥0.006/封**（充多少用多少） | platform.deepseek.com | **现在测试用**，已实测通过 |
| `gemini` | **免费 1500 次/天** | aistudio.google.com | 长期跑，量大不花钱 |

切换只改两行：`"provider": "gemini"` + 把 `api_key` 换成 Google 那串。代码其余部分完全不动。

**实测结果（DeepSeek，2026-07-31）**：3 封样本全部分类正确 —— 换货问题→customer、200件批发→lead、PayPal 争议→high_risk 且草稿为空。待办日期解析正确（"next Wednesday"→2026-08-05，争议截止→2026-08-07）。

## 真跑三步

**1. 装依赖（一次）**
```
pip install requests
```

**2. 填 config.json**

| 字段 | 填什么 |
|---|---|
| `provider` | `deepseek` 或 `gemini` |
| `api_key` | 对应平台的 key |
| `gmail_address` | 客户的 Gmail |
| `app_password` | 客户生成的 16 位应用专用密码 |
| `owner_context` | 一句话说清客户是干什么的，草稿会准很多 |

`accounts` 是数组，**有几个客户写几个，一条命令全跑完**。

**3. 跑**
```
python triage.py --open        # 最近 1 天
python triage.py --days 3      # 最近 3 天
python triage.py --all         # 忽略去重，重跑全部
```

报告落在 `out/<邮箱名>_<日期>.html`，直接当附件发客户。

## 代码写死的安全约束（改不了）

| 约束 | 在哪实现 |
|---|---|
| 永不发信、永不删信 | `mailbox.py` → `select(INBOX, readonly=True)` |
| 高危 + 垃圾邮件永不生成草稿 | `ai.py` → `if cat in ("spam","high_risk"): reply_draft=""` |
| 不编造订单号/价格/日期 | prompt 强制用 `[方括号占位符]` |
| 日期格式非法自动丢弃 | `ai.py` → 正则校验 `YYYY-MM-DD` |
| 不重复烧 API 额度 | `store.py` SQLite 按 uid 去重 |

## 一个必须知道的事：DeepSeek 是中国服务器

你的客户是老外，邮件内容是他们的隐私。用 DeepSeek 意味着**邮件正文会发到中国境内服务器**。

- **自己测试阶段**：无所谓，随便用。
- **开始收老外的钱之后**：要么换成 Gemini（Google，美国），要么在隐私条款里如实写明数据处理方。别偷偷摸摸——被发现一次，信任就没了，而这个产品卖的就是信任。

建议：**现在用 DeepSeek 测，正式接客户前换 Gemini。** 代码已经支持，改一个字段的事。

## 常见报错

**`FAILED to connect`**
客户没开两步验证 / 应用专用密码抄错 / Gmail 里 IMAP 没打开
（Gmail → Settings → Forwarding and POP/IMAP → Enable IMAP）

**`HTTP 402 Insufficient Balance`**
DeepSeek 余额用完了，去 platform.deepseek.com 充值，或切 gemini。

**`HTTP 429`**
Gemini 免费档每分钟 15 次。代码会自动退避重试，只是慢点，不会崩。
